# KKAMURUK(까무룩)

잠들기 어려운 밤, 짧은 대화와 마법약 한 병의 위로.

KKAMURUK은 AI와 나눈 이야기를 바탕으로 마법약 처방과 짧은 위로 메시지를 전하는 웹 서비스를 목표로 합니다.

[서비스 접속](https://codyssey1-termproject-production.up.railway.app)

## 까무룩을 소개합니다

잠들기 전 머릿속에 남은 생각과 감정을 누군가에게 이야기하고 싶은 순간이 있습니다. KKAMURUK은 잠들기 어려운 사용자가 짧은 대화로 자신의 마음을 표현하고 위로를 받을 수 있도록 기획했습니다.

## 서비스 경험

회원가입/로그인 → AI와 짧은 대화 → 나의 이야기를 담은 마법약 → 위로 메시지

- **나의 이야기를 이어가는 대화**: 앞서 나눈 이야기를 바탕으로 자연스럽게 이어가는 대화를 지향합니다.
- **마법약으로 표현하는 마음**: 나눈 이야기를 마법약의 색으로 표현합니다.
- **짧은 위로**: 대화를 마무리하며 읽을 수 있는 위로 메시지를 서비스의 핵심 경험으로 삼았습니다.
